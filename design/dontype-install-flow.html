隐私政策 · Dontype

Easylii 出品 · 生效 2026-06-17

你的声音永不离开这台 Mac。零收集、零追踪、无账号、无埋点 —— 这个 App 从设计上就让我们接触不到你的数据。

1. 语音转写(本机完成)

听写时音频在你的 Mac 本地转成文字(whisper / Apple 识别),只在转写那一刻留在内存,随后丢弃,绝不上传。

2. 可选 AI 整理(用你自己的账号)

开启时仅把转写文字(非音频)发到你配置的服务商(Anthropic / OpenAI),走你自己的 key 或订阅,受其隐私政策约束。不配置则不发送。可随时关闭。

3. 我们不做的事

不在服务器收集/存储你的音频或文字;无分析、埋点、崩溃上报、追踪;无账号、无广告;不出售、不共享数据;不嵌入收集数据的第三方 SDK。

4. 本机文件

设置、本地日志、上次转写结果都只存在你的 Mac(~/.config/siyu/),不会传给我们,可随时删除或卸载清除。

5. macOS 权限

麦克风(采集语音)、语音识别(本机转写)、辅助功能(监听热键 + 粘贴到光标)。仅用于上述功能,可随时在系统设置撤销。

6. 你的权利(GDPR / CCPA 等)

我们不持有你的个人数据,这边无可访问/删除项;你完全掌控本机数据。AI 服务商处理的数据请直接向其申请。
